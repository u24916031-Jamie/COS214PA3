PGA Championship
The culmination of the 2026 PGA Tour, featuring the top performing players from throughout the season for an exciting bout to find who will be crowned champion.
Players can play golf holes and their score will be tracked. Spectators may visit one of the many vendors available and purchase a myriad of goods.

To run:
-run make in the main directory. This will create and run eventflow in the bin file
-For fitchfork compliant: Open the submission folder and run make 

Doxygen:
In the docs/html folder open index.html and use the buttons to navigate the doxyfile
